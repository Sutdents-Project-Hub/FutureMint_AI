# FutureMint AI 決賽 Demo 腳本

## 展示前準備

1. 開啟 Coolify production Flutter Web，確認登入畫面與 HTTPS。
2. 使用專為決賽建立的 synthetic test account；預先查看 AI 資料說明並明確啟用，台上不顯示 email、password、token、key、database URL 或 Coolify secrets。
3. 確認 `/api/health` 為 ok、PostgreSQL healthy、`ALLOWED_ORIGINS` 正確。
4. 先用合成文字確認量界 model 可用；若無網路，改用明確標示的訪客／deterministic demo。
5. 投影解析度先測 1440×900；手機備援測 375px。

## 四分鐘主線

這是團隊計時演練的精煉主線，不是主辦方已確認的上台時長；收到正式時長後，以這條「輸入 → 看懂 → 學習 → 行動」故事按比例縮放。投資練習場、角色與設定留給 Q&A，不在主線搶走問題與成果的時間。

### 0:00–0:25　登入與資料界線

「FutureMint 讓每個帳號只看到自己的預算、紀錄與微課。資料由後端 session 驗證並保存到 PostgreSQL；訪客模式不保存。」

登入 synthetic account，指出已登入狀態，不露 credentials。

### 0:25–0:45　問題與首頁

「小恩開始管理零用錢與數位訂閱，但大部分工具只記帳，不會在選擇當下幫他看懂影響。」

指出本月安心可用、目標、近期紀錄與非責備式提醒。明說資料是合成。

### 0:45–1:35　Quick Capture

輸入：

```text
今天買珍奶 75
```

按「幫我整理」，App 收起鍵盤並捲至第一筆確認草稿；「再記一筆」輸入區位於草稿後。停在草稿：

- 指出來源是「量界智算 AI 解析」；備援若是 deterministic demo 必須照實說。
- 說明 parse 不等於保存，可改金額、項目、分類與 AI 建議的需要／想要。
- 按「確認並記下」後，API 才寫 PostgreSQL 並更新預算。

加分可改用 `Netflix 390，四個人分`，以同一筆資料自然帶出下一段的訂閱檢查。

### 1:35–2:05　分析與訂閱提醒

先看六個月收支與需要／想要比例，再開啟續訂提醒與方案比較。說明提醒是邀請檢查使用頻率，不代表一定浪費；價格是合成展示資料。

### 2:05–2:40　個人學習規劃

進入學習，指出需要／想要、固定支出、複利與風險四段路線，再選一項微課行動。說明量界只收到最小摘要，輸出仍經 schema 驗證。

### 2:40–3:25　FutureSeed 與 AI 陪讀員

以已省 4,200 元、每月 500 元、5 年比較三條版本化合成曲線。點「慢慢長」或「高風險資產」的回落，詢問「為什麼中間掉下去？」；說明金額與最大回落由程式計算，AI 只白話解釋，曲線不是即時行情、買賣建議或報酬保證。

手機頁面先顯示投入與期間控制，按下「開始教育試算」成功後會捲至曲線，再看結果與陪讀；投資練習場入口在後，留給 Q&A。2026-10-02 排版巡檢與自動化結果見 [測試證據](testing-and-evidence.md)，本機預覽不代表線上帳號流程已驗收。

### 3:25–4:00　技術收尾

「正式 iPhone 直接連 Coolify API，資料保存在獨立 PostgreSQL Resource；Flutter Web 只供選用測試。Flutter 以 Bearer token 呼叫 Fastify，後端才可接觸量界金鑰與資料庫；AI 回覆先過 schema，金額與複利由程式計算。Coolify 從 private GitHub 的 main 自動部署，不會讀我的電腦。」

若評審仍問 Azure，明確說明主辦方已關閉環境、團隊改用自有 VPS 替代，並出示已取得的規則確認；不可把替代架構稱為 Azure。

## Q&A 備用展示

- 投資練習場：20 秒指出 TWSE 延遲日期、虛擬現金、事件骰子與不提供買賣建議；只在被問到風險教育或資料來源時打開。
- 孩子／家長角色與設定：展示家長建立 24 字元邀請碼、孩子加入，以及家長只看到預算／趨勢摘要、不看到交易明細；邀請可更新或停用，完整共管與所有權轉移仍未提供。
- 隱私控制：展示量界智算的資料類別／用途、拒絕後仍可用的功能、撤回入口，以及需目前密碼與雙重確認的帳號刪除流程；不在台上真正刪除 demo account。
- Coolify：只展示 Web／API health 與 PostgreSQL Resource 的 healthy 狀態，不露 private repository、database URL 或 secrets。

## 正式產品模式補充

以下只在完成授權與部署驗收的環境執行：SMTP 模式在 Email 註冊後先完成收信驗證，再進首次設定；示範忘記密碼時使用已驗證的合成帳號，重設後舊登入失效。家長建立的邀請碼只顯示一次，可更新或停用，孩子輸入時區分大小寫。教育頁應說明「AI 選題，受控教材提供內容」。SMTP 未啟用的正式環境亦不要求 Email 驗證；必須揭露未驗證識別與寄信重設停用，15–17 歲仍不能繞過監護人同意。

## 本輪上架功能示範

AI 資料說明依供應商、傳送內容、啟用狀態與個人選擇分段閱讀；隱私及支援連結靠左，完整版本從「詳細資訊」展開。此排版調整保留原揭露與啟用門檻。

2026-10-02 實際登入模擬器巡檢補充：AI 未啟用顯示淡紫資訊卡，可從「查看資料用途」檢查狀態；供應商說明未完成時展示手動與固定教材，不宣稱真實 AI 成功。訂閱／預算彈窗保存與取消的退場錯誤已修復。虛擬下單前指出金額為預估，送出後看操作區的實際單價／資料日及行情更新提示；不能承諾以先前畫面的備援價格成交。通知拒絕時指出設定內的恢復方法。實際覆蓋與限制見測試證據。

正式展示前先用合成帳號跑 Email／年齡／監護人資格；不要以真人未成年人資料做試驗。15–17 歲帳號示範監護人信件中的 requester Email、成人及法定代理人聲明；說明與家庭摘要／AI 同意獨立，Email 不是監護身分查核。

在訂閱頁建立月繳或年繳合約，先指出承諾成本，再另外記付款或採用舊付款，確認沒有重複支出；編輯／停止保留實付。紀錄翻頁後摘要不變；示範手動輸入與本人 JSON 匯出。iPhone／Android 提醒選擇啟用；拒絕後示範「開啟通知設定」與返回更新，再啟用。明示 Android 送達可能受省電延後；Web 示範 App 內提醒，不說 APNs／FCM。裝置權限或送達未實測時只展示已驗證步驟。

AI 政策頁顯示當前 provider／模型／接收方；拒絕後手動功能與受控教材仍可用。不在 Demo 中改 production provider、使用真實 secret、送審或操作 backup。部署示範只能描述已觀察結果：使用者說明既有 Coolify 曾成功部署，本輪重新部署／live health 尚待驗收。

簡化部署示範：未設定 SMTP 時可示範成年合成帳號的免寄信註冊／登入及訪客；不宣稱 Email 已驗證或寄信成功，15–17 歲仍停在待同意。未完成供應商說明時僅展示手動與固定教材，不宣稱真實AI成功。訪客資料結束後清除；本輪不示範或宣稱定期備份已設定。

## 親子流程 Q&A 補充（2026-10-02）

以合成家長／孩子帳號展示：各自註冊及設定 → 必要的監護人確認 → 家長建立邀請 → 孩子確認摘要分享 → 家長看摘要 → 孩子退出。首次設定填的是登入者自己的預算。監護人、家庭與 AI 三種同意各自獨立；取消家庭確認不加入，唯讀也能停止分享。

無 SMTP 的最小 API 可展示成年／訪客與未成年待確認狀態，不能把它說成新未成年正式流程已可完成。mock mailer／模擬器合成預覽不是正式監護人送達；最新驗證見測試證據。
